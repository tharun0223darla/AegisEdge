# Prescription Medicine Annotation

Local annotation tool for real prescription images. Keep this dataset local
because the images may contain patient and doctor details.

## Start

If you have a zip of prescriptions, import it first:

```powershell
ocr-service\.venv\Scripts\python.exe tools\prescription-annotation\import_zip_dataset.py C:\Users\tharu\Downloads\archive.zip --replace
```

This creates `datasets\prescription_medicine_detection`, copies the images,
creates train/val/test splits, initializes COCO labels, and writes geometry
prelabels for review.

```powershell
node tools\prescription-annotation\server.mjs datasets\prescription_medicine_detection
```

Open:

```text
http://127.0.0.1:4677
```

## Labeling Rules

- Turn on `Show prelabels` to view raw auto labels generated by geometry.
- Click `Accept Prelabels` to copy the current image's raw auto labels into
  editable boxes.
- Click `Save reviewed` after accepting/fixing boxes. Raw auto labels are not
  part of the final training annotations until you save them.
- Draw a tight box around only the visible medicine name.
- Type the visible medicine name exactly as written.
- Do not include dose, route, schedule, quantity, duration, or advice unless it
  is physically attached to the medicine name and cannot be separated.
- Draw extra boxes around common false positives and mark them as `signature`,
  `advice`, `patient_detail`, `vitals`, `stamp`, or another non-medicine type.
- Save every reviewed image before moving on.

## Exports

`Export YOLO` writes medicine-name detector labels to:

```text
datasets\prescription_medicine_detection\exports\yolo_medicine_name
```

Only `medicine_name` boxes are included in this export.

`Export Qwen Crops` writes crop-level fine-tuning data to:

```text
datasets\prescription_medicine_detection\exports\qwen_medicine_name_crops
```

This export includes positive medicine-name crops and hard-negative crops such
as signatures/advice. Medicine boxes without a typed medicine name are skipped
so they do not poison the fine-tuning set.

## Validate

```powershell
node tools\prescription-annotation\validate_detection_dataset.mjs datasets\prescription_medicine_detection
```

## Batch-Test Current Vision Pipeline

Run a small smoke test first:

```powershell
ocr-service\.venv\Scripts\python.exe tools\prescription-annotation\run_vision_batch.py --limit 1 --force
```

Run all prescriptions:

```powershell
ocr-service\.venv\Scripts\python.exe tools\prescription-annotation\run_vision_batch.py --resume
```

Reports are written to:

```text
datasets\prescription_medicine_detection\exports\vision_batch
```

Use `summary.csv` to find weak cases and `review.html` for a quick browser
review. The command is resumable, so you can stop and continue later with
`--resume`.
